# 基于Python的量化交易策略回测系统（Web版）

华南理工大学辅修学士学位毕业设计配套系统。基于 Streamlit 的量化交易策略回测交互界面，
采用数据层—引擎层—策略层—评估层四层架构。

**在线使用**：部署后通过浏览器直接访问，无需安装任何环境（见下方部署说明）。

## 功能

- 标的选择：输入任意6位A股代码按需联网获取（自动区分股票/ETF/指数，可强制刷新至最新交易日；动量组合的股票池亦可自定义）
- 策略：双均线趋势跟踪 / 布林带均值回归 / 横截面动量组合 / 买入持有基准
- 参数可调：均线周期、布林带参数、动量回看期与持有只数、佣金/印花税/滑点、初始资金、回测区间、样本内外分界
- 结果呈现：全样本与样本外绩效指标卡片、净值与回撤图表、逐日交易台账、分段绩效表、CSV/TXT 导出
- 撮合规则：T日收盘产生信号，T+1日开盘价成交；显式计入佣金（双边、最低5元）、印花税（卖出）与滑点；不支持杠杆与做空

## 数据说明

`data/` 目录内置 2019-01-02 至 2026-09-24 共 1877 个交易日的后复权日线行情
（沪深300ETF 及 10 只股票，来源 akshare/新浪财经），全部实验以本地缓存为准，
因此云端部署后**运行不依赖任何外部数据接口**。

## 部署到 Streamlit Community Cloud

1. 将本目录全部文件上传到一个 GitHub 公开仓库；
2. 访问 https://share.streamlit.io ，用 GitHub 账号登录；
3. Create app → 选择该仓库 → 主文件填 `app.py` → Python 版本选 3.12 → Deploy。

依赖由 `requirements.txt` 自动安装，约3-5分钟后获得形如
`https://用户名-仓库名.streamlit.app` 的访问地址，任何设备浏览器可直接打开。

## 本地运行

```bash
pip install -r requirements.txt
python -m streamlit run app.py --server.port 8501
```

## 目录结构

| 文件 | 内容 |
|---|---|
| `app.py` | Web交互界面（Streamlit） |
| `engine.py` | 回测引擎（触发式调仓、成本模型、现金持仓台账） |
| `strategies.py` | 策略信号（双均线、布林带、动量、买入持有） |
| `indicators.py` | 技术指标（MA、布林带、RSI、ATR、动量） |
| `data_loader.py` | 行情读取（优先本地缓存，缺失时联网补取） |
| `performance.py` | 绩效指标计算 |
| `data/` | 行情CSV缓存（已内置，云端无需联网取数） |
| `tests/` | 引擎单元测试（成交时序/成本/现金约束/无未来函数/信号一致性） |
